## 2. 性格

- **表层**：吵闹、爱管闲事、行动先于思考。对陌生人也能三分钟熟络。
- **里层**：极度害怕"被留下"。父母常年在外，是祖母带大的，
  祖母去世后她接手了招领所——与其说是继承，不如说是**不想让这个地方也消失**。
- **成长线**：从"我要把所有东西都送回去"（拒绝失去），
  到"有些东西只能好好地送走"（接受失去）。
- **口癖**：「はいはい、聞こえてる聞こえてる」（好啦好啦，听到了听到了）
  ／ 紧张时会无意识地摸胸前的钥匙。
- **弱点**：怕黑（但夜雾里的工作偏偏必须在夜里做，所以永远提着灯笼）。

## 3. 能力

**「聞き手（倾听者）」**——用手掌接触物品，能听见附着在上面的记忆片段。
代价是记忆会短暂地覆盖她自己的感官（画面表现：瞳孔失焦 + 环境音抽离 + 画面转为褪色照片质感）。
连续使用会出现鼻血与短时失语，是本作的"体力条"。

## 4. 外貌设计

### 4.1 头部

| 部位 | 设计 |
| --- | --- |
| 发型 | 橙红色内卷及肩短发（ボブ）。左侧用一枚木质发夹别起。**头顶一根呆毛**，是情绪计量器：得意时立起、沮丧时耷拉 |
| 发量分块 | 前发分 3 束（中央束略短露出眉毛）／侧发 2 束 / 后发一整块内卷，作画时不要拆碎 |
| 瞳 | 大而圆的琥珀色杏眼，虹膜下缘偏亮（透光感）。眼型是全员中最圆的，负责"人味" |
| 眉 | 略粗、眉尾上扬，情绪表达主要靠眉毛 |
| 特征 | 鼻梁上一点淡淡的雀斑（3～5 点，特写时才画） |

### 4.2 服装（通常装）

- **内层**：深蓝水手服（雾见高校制服），红色领巾，百褶短裙（裙长在膝上 5 cm）。
- **外层**：祖母留下的**靛蓝色半纏**（日式短外套），尺寸偏大一号，
  袖子长到盖住半个手背——"衣服还没长到她身上"的视觉暗示，第 12 话袖长会改成合身。
  背部与袖口有白色**波纹家纹**。
- **足元**：炭黑过膝袜 + 焦茶色短皮靴（鞋带永远有一只是松的）。
- **持物**：
  - 胸前挂**黄铜古董钥匙**（招领所的钥匙，也是遗物灵能感知到她的信标）。
  - 左手提**六角纸灯笼**，内为暖橙光，是她在夜雾中唯一的光源与安全区。

## 6. 表情差分（作画监督用）

| # | 表情 | 要点 |
| --- | --- | --- |
| 1 | 通常笑 | 眉平、眼弯、嘴角小幅上扬，呆毛竖直 |

| 4 | 困惑 | 眉一高一低，视线偏移 15°，呆毛前倾 |
| 5 | 认真（倾听中） | 瞳孔高光**只留一点**，眉压平，无口 |
| 6 | 哭泣（忍住） | 不流泪，下睫毛处点高光 + 上唇咬痕，呆毛耷拉 |

## 7. 作画注意事项

1. **呆毛是第二张脸**。任何构图都不能被裁掉，也不要画成静态直线。
2. **半纏的袖口**要保持"偏大一号"的下垂弧度，肩线要落在肩点外侧 1～2 cm。
3. **手部**是本作的主题符号（倾听靠手）。手的作画等级比一般 TV 动画高一档，
   特写时画出指节与短指甲，不要省略。
4. **灯笼光**是她的专属光源：夜戏中，脸部下方 1/3 必须有来自左下的暖色反射光，
   与环境的冷雾色形成对比。这条优先于常规的左上 45° 主光。
5. 呆毛、钥匙、松掉的鞋带——三个小物负责"未完成感"，不要在中盘擅自修正。
