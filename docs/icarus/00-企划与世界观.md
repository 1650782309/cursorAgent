# 《黄昏之羽》企划与世界观

> 想定媒体：日式幻想 RPG 手游（角色卡立绘 / Live2D）
> 画风基线：柔和梦幻的日式幻想手游立绘，柔和赛璐璐 + 水彩渐变，低对比度阴影

本企划与本仓库另一部作品《雾见町 遗物招领所》**无世界观关联**，
画风、媒体、制作规范均独立。两者放在同一仓库中只是作为设定集合管理。

---

## 1. 企划定位

伊卡洛斯是本企划的**首位设计角色（主视觉担当）**。
世界观的存在意义是"让这个角色站得住"，因此以下设定全部围绕她的视觉元素反向推导：
羽翼、光轮、青蓝魔法宝石、粉色能量羽毛、黄昏都市。

若后续扩充角色，请遵守 [03-企划共通规范](03-企划共通规范.md) 中的视觉公约。

---

## 2. 舞台：天层都市「艾莉西恩」（Elysion）

建在云海之上的多层浮空都市，由下至上共九层，越高越接近"神域"。
黄昏是这座都市的常态——它悬停在恒定的日落带上，天空永远是桃粉、金与紫的渐变。

| 要素 | 设定 |
| --- | --- |
| 天空 | 恒定黄昏。正午与深夜只存在于古籍记载中 |
| 结构 | 九层环形高台，以巨大的桥梁与升降回廊连接，远景可见高塔与穹顶 |
| 光源 | 低角度的暖金色阳光 + 都市本身的魔导灯（暖橙） |
| 视觉母题 | 逆光、大气雾、飘散的羽毛、半透明薄纱、水面与石砖的反光 |

> 美术方向：环境永远是**低对比度的暖色雾**，角色是画面中唯一清晰锐利的存在。
> 环境只做氛围衬托，不与角色争夺视觉重心。

---

## 3. 核心设定：羽者（Winged）

被"天层"选中、背生羽翼的人。全都市不足二十人，同时是神职、执法者与祭品。

**三条法则**

1. **羽翼即寿命**。羽者每一次使用力量，都会永久失去一部分羽毛。
   飞散的羽毛化为粉色的光，这就是伊卡洛斯身边那些浮游羽毛的真身——
   **它们不是装饰，是她正在流失的生命。**
2. **光轮即枷锁**。头后的环形光轮由天层授予，带有细小的尖刺。
   它既是神圣的徽记，也是无法摘下的项圈：羽者违抗天层时，尖刺会向内收紧。
3. **坠落**。羽毛耗尽的羽者会从第九层坠入云海之下，无人知道下面有什么。
   都市把这称为"归还"，羽者自己称之为"坠落"。

> 角色名「伊卡洛斯」正取自这条法则——一个注定要坠落的名字。
> 她本人知道这件事，所以她的表情里那份慵懒与忧郁，是设计上的必然而非风格化选择。
