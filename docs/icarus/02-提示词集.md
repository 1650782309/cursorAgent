# 伊卡洛斯 · 提示词集（整合优化版）

原始提示词为一整段连续文本，重复项多、优先级不明、难以复用。
本文件将其重构为**可组合的模块**：每次出图 = `角色锁定块` + `场景块` + `画风块` + `负向块`。
这样换姿势、换背景、做差分时只替换其中一块，角色本身不会走形。

**使用方法**：在本地 Cursor Desktop（2.4 以上）的 Agent 会话中，
把需要的几个代码块拼接后发给 Agent 并说明要生成图片。
生成结果建议存到 `assets/icarus/`。

> 中文版适用于对中文敏感的模型（如 Nano Banana Pro）；
> 英文版适用于 SD / Flux / NAI 系。两版内容严格对应，修改时请同步。

## 5. 参数与一致性建议

| 项目 | 建议 |
| --- | --- |
| 宣传立绘长宽比 | **9:16**（角色卡）或 3:4 |
| 设定稿长宽比 | **16:9**，且分辨率尽量拉高（设定稿信息密度大，低分辨率必糊） |
| 采样步数 / CFG | SD 系：steps 28～35，CFG 6～8（CFG 过高会让低对比度画风变硬） |
| 种子 | 出到满意的一张后**固定 seed**，再做差分与换背景 |
| 权重 | 若模型支持，给核心识别符加权：`(glowing cyan-blue magic gemstone:1.2)`、`(half-lidded violet eyes:1.15)`、`(natural feathered angel wings:1.3)` |

**保持三视图一致的实操顺序**（一次性生成整张设定稿成功率很低）：

1. 先只用 `角色锁定块 + 画风块` 出**正面全身图**，反复抽到满意。
2. 固定 seed，把该图作为**参考图**输入，再分别生成侧面与背面。
3. 局部（眼睛、光轮、法杖、鞋）单独出图，分辨率更高、细节更准。
4. 最后把所有素材拼合为设定稿版式，而不是让模型一次画完。

## 7. 常见失败与修补词

出图跑偏时，按下表在负向或正向中追加对应词。

| 症状 | 修补方法 |
| --- | --- |
| 翅膀变成机械/装甲 | 正向加 `(soft natural bird feathers:1.4)`，负向加 `mechanical wings, armor plating, metal wings` |
| 光轮变成科技环 / 发光圆盘 | 正向改为 `thin ornamental metal ring halo with tiny spikes and feathers`，负向加 `glowing disc, neon ring, hologram, hud` |
| 眼睛画成大睁圆眼 | 正向加 `(half-lidded sleepy eyes:1.3)`，负向加 `wide open eyes, surprised expression` |
| 法杖变成大剑 / 重型武器 | 正向加 `slim lightweight ceremonial staff`，负向加 `greatsword, heavy weapon, spear, scythe` |
| 薄纱糊成实心布料 | 正向加 `(translucent sheer chiffon, see-through fabric:1.2)` |
| 背景抢戏 | 正向加 `blurred background, strong bokeh, shallow depth of field` |
| 出现多个角色 | 正向开头加 `solo, 1girl`，负向加 `multiple characters, crowd` |
| 头发变长 | 正向加 `(short bob haircut, hair above shoulders:1.3)`，负向加 `long hair, twintails` |
| 尺度失控 | 负向加 `nsfw, nude, cleavage focus, revealing`，正向加 `fully clothed, modest coverage` |
