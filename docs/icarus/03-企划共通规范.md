# 《黄昏之羽》企划共通规范

本企划所有角色共通。作画基线与《雾见町 遗物招领所》**一致**——现代日本 TV 动画赛璐璐，
线稿、阴影分层、检查流程均按同一套量产规范执行。详细数值与通用材质表见
[`docs/kirimicho/05-作画规范.md`](../kirimicho/05-作画规范.md)；本节只写本企划的**追加规则与差异**。

| 对比项 | 两企划共通基线 | 《黄昏之羽》追加取向 |
| --- | --- | --- |
| 线稿 | 锐利、粗细分级、`#2A2530` | 同左；银饰与羽毛细部可用 1.0 px 线 |
| 阴影 | 硬边赛璐璐，1 影 −18% / 2 影 −32% | 同左；**禁用**水彩渐变与柔光虚化 |
| 上色 | 扁平色块，禁用大面积渐变 | 羽翼用**分段平涂色带**代替空气笔渐变 |
| 头身 | 依角色表 | 主要角色 **7.8～8.2 头身**（伊卡洛斯 8.0） |
| 目的 | TV 动画量产可行性 | 幻想元素（羽翼、光轮、宝石）在赛璐璐框架内可读 |

---

## 1. 画风基线

- 现代日本 **TV 动画角色设定**取向：干净锐利的线稿、扁平色块、硬边阴影。
- 设定稿与作监检查：**纯白底 + 浅灰网格**（与雾见町 [`07-立绘生成提示词`](../kirimicho/07-立绘生成提示词.md) 共通前缀一致）。
- 正片 Key Visual / 背景戏：可保留艾莉西恩的黄昏都市与大气雾，但**角色本体的线稿与赛璐璐块面仍须硬边**，背景不得用柔光虚化替代角色阴影。
- 关键词：圣洁、梦幻、神秘、成熟——通过**造型与配色**表达，不通过手游立绘式柔光滤镜表达。

## 2. 线稿与赛璐璐分层

通用线稿粗细与 7 层上色流程见雾见町 [`05-作画规范` §3～§4](../kirimicho/05-作画规范.md)。

本企划追加：

| 线种 | 粗细 | 用途 |
| --- | --- | --- |
| 羽轴 / 飞羽轮廓 | 1.5 px | 羽翼外缘与主羽轴 |
| 宝石切面 | 1.0 px | 胸口宝石、杖尖水晶的内部结构线 |

**特效层（第 7 层）**在本企划中固定为：

- 浮游羽毛 `#FFB6CE`（自发光，外辉 `#FFD9E6`）
- 魔法宝石 / 杖尖 `#4FD8F5`（核心 `#E8FEFF`，外辉 `#7FE9FF`，**硬边高光**）
- 羽翼内侧冷反射 `#CBBBE6`（细条，非渐变喷枪）

## 3. 光照规则

### 3.1 设定稿 / 日常作监（默认）

- **主光**：左上 45°（与雾见町一致）。
- **环境反射光**：轮廓内侧一条细亮边，取淡紫 `#CBBBE6` 或环境主色。
- 宝石与浮游羽毛的自发光**不替代**主光源阴影，只在贴近表面处叠一层硬边亮块。

### 3.2 正片 / Key Visual（例外）

剧情需要艾莉西恩「恒定黄昏」时使用第二套光源，**与主光叠加而非取代**：

1. **暖轮廓光**：来自角色背后的低角度夕阳，桃粉—金色，**硬边 rim**（2～3 px），不用 5 px 以上柔光晕。
2. **冷自发光**：宝石、杖尖、羽翼内侧，青蓝 `#4FD8F5` 与淡紫 `#CBBBE6`。

两套光可同时存在；交付作监检查时仍须满足 §3.1 的赛璐璐块面可读性。

## 4. 材质表现（赛璐璐版）

| 材质 | 表现方法 |
| --- | --- |
| 半透明薄纱 | 1 影 + 高光两层；叠加处**只提高不透明度**，不喷渐变。透出下层结构须可辨，薄纱与皮肤之间留空隙 |
| 丝绸飘带 | S 形转折 + **硬边**带状高光，褶皱少而明确 |
| 羽毛 | 分三层平涂：绒羽（根部）→ 覆羽 → 飞羽。**色带** `#FDFAF6` / `#BFE3F2` / `#CBBBE6` / 边缘 `#FFB6CE`，禁止空气笔渐变 |
| 水晶 / 宝石 | 三段式硬边：暗底 + 中间色 + 近白高光块；外辉一圈硬边，不用柔光外发光 |
| 银色花饰 / 光轮 | 同雾见町黄铜/银：暗底 + 中间色 + 一点 `#FFFFFF` 高光 |
| 皮肤 | 暖白 `#FBEDE4`，1 影 `#EFD0C4`，红晕 `#F3B3B0`；禁止毛孔与写实质感 |

## 5. 视觉公约（后续角色须遵守）

1. **一人一色**：每个角色只能有一种高饱和「灵性色」，出现位置不超过 5 处。
   伊卡洛斯已占用青蓝 `#4FD8F5`，后续角色请另择。
2. **羽翼必须是生物结构**。禁止机械翼、装甲翼、几何能量翼。
3. **光轮是神圣徽记**，不是科技设备：无电路、无 HUD、无全息投影。
4. **武器轻量化**。细长、优雅、轻盈，禁止重型武器与枪械。
5. **尺度守则**：可低领口、露肩、露腿，但必须完整穿着、结构明确，不做露骨表达。
6. **环境不抢戏**（正片）：背景可虚，但角色线稿与色块必须最清晰；设定稿一律白底网格。

## 6. 提交前检查表

- [ ] 头身比与角色设定表一致（伊卡洛斯 8.0 头身）
- [ ] 线色 `#2A2530`，未使用纯黑；眼睛高光两点制（11 点 / 5 点）
- [ ] 配色 HEX 与设定表一致，未出现设定外的高饱和色
- [ ] **硬边赛璐璐**：1 影 / 2 影分层正确，无 watercolor、无柔光糊阴影
- [ ] 羽翼为自然羽毛 + **分段平涂**，无机械化、无喷枪渐变
- [ ] 光轮无科技感元素
- [ ] 薄纱透出结构可辨，未糊成实心布料
- [ ] 浮游羽毛数量与该场景的力量消耗相符
- [ ] 手部与手指数量正确，法杖握持自然
- [ ] 尺度符合守则，无露骨表达
- [ ] 剪影测试：填黑后可读出羽翼、光轮、法杖、波波短发四个特征
