# 《黄昏之羽》企划共通规范

本企划所有角色共通。与《雾见町 遗物招领所》的作画规范互不适用——
两者在线稿、阴影、材质三个层面的取向完全相反，切勿混用。

> **例外**：[`assets/icarus/concepts/icarus-keyvisual.png`](../../assets/icarus/concepts/icarus-keyvisual.png)
> 概念立绘 intentionally 采用雾见町 TV 动画赛璐璐画风（见 [`02-提示词集`](02-提示词集.md) §3-B），
> 作为跨企划视觉实验；企划正片/手游基线仍以本节为准。

| 对比项 | 《雾见町》（TV 动画） | 《黄昏之羽》（手游立绘） |
| --- | --- | --- |
| 线稿 | 锐利、粗细分级明确、`#2A2530` | 纤细柔和、带手绘颤动、色トレス为主 |
| 阴影 | 硬边赛璐璐，明度差 −18% / −32% | 半硬边，低对比度，明度差不超过 20% |
| 上色 | 扁平色块，禁用渐变 | 赛璐璐 + 水彩渐变混合 |
| 目的 | 量产可行性 | 单张信息密度与华丽度 |

---

## 1. 画风基线

- 柔和梦幻的日式幻想手游角色立绘，经典日式幻想 RPG 气质。
- 细腻柔和的动漫线稿，轻微手绘感；线条不使用纯黑，一律取该区域底色的加深版。
- 柔和赛璐璐与水彩渐变结合，**低对比度阴影**，阴影边缘半硬。
- 优雅修长的人体比例（主要角色 7.8～8.2 头身）。
- 关键词：华丽但轻盈、圣洁、梦幻、神秘、成熟。

## 2. 光照规则

固定两套光源，缺一不可：

1. **暖光（主光）**：来自角色背后的黄昏，形成柔和的金色轮廓光。
   色相偏桃粉与金，边缘柔化 3～5 px，不产生硬投影。
2. **冷光（自发光）**：来自魔法宝石、水晶与羽翼边缘，青蓝 `#4FD8F5` 与淡紫 `#CBBBE6`。
   只影响近距离表面（宝石周围的胸口、握杖的手、羽翼内侧）。

环境光对皮肤的影响要保留通透感，禁止把皮肤压成灰色。

## 3. 材质表现

| 材质 | 表现方法 |
| --- | --- |
| 半透明薄纱 | 叠加处只提高不透明度，不加深轮廓线；透出的结构必须可辨，不糊成一片。薄纱与皮肤之间留空隙 |
| 丝绸飘带 | 长而连贯的 S 形曲线，高光为细长带状，褶皱少而柔 |
| 羽毛 | 分三层：绒羽（根部蓬松）→ 覆羽 → 飞羽（末端整齐）。渐变沿羽毛长度方向 |
| 水晶 / 宝石 | 内部有多面反射，核心留一块近白的高光，外围加一圈柔和外辉 |
| 银色花饰 | 三段式：暗底 + 中间色 + 一点纯白高光。形状为花朵与藤蔓，禁用几何工业形态 |
| 皮肤 | 通透暖白，低对比度，禁止毛孔与写实质感 |

## 4. 视觉公约（后续角色须遵守）

1. **一人一色**：每个角色只能有一种高饱和的"灵性色"，出现位置不超过 5 处。
   伊卡洛斯已占用青蓝 `#4FD8F5`，后续角色请另择。
2. **羽翼必须是生物结构**。本企划禁止一切机械翼、装甲翼、几何能量翼。
3. **光轮是神圣徽记**，不是科技设备：无电路、无 HUD、无全息投影。
4. **武器轻量化**。本企划的武器一律细长、优雅、轻盈，禁止重型武器与枪械。
5. **尺度守则**：可以低领口、露肩、露腿，但必须完整穿着、结构明确，
   不做露骨表达。薄纱透出的部分要能看出服装结构。
6. **环境不抢戏**：背景一律浅景深 + 大气雾，角色是画面中唯一清晰的主体。

- [ ] 暖色轮廓光与冷色自发光同时存在
- [ ] 阴影为低对比度、半硬边，未出现硬赛璐璐块面
- [ ] 羽翼为自然羽毛结构，无机械化处理
- [ ] 光轮无科技感元素
- [ ] 薄纱透出结构可辨，未糊成实心布料
- [ ] 浮游羽毛数量与该场景的力量消耗相符
- [ ] 手部与手指数量正确，法杖握持姿势自然
- [ ] 尺度符合守则，无露骨表达
- [ ] 剪影测试：填黑后可读出羽翼、光轮、法杖、发型四个特征
