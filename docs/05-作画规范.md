# 作画规范（キャラクター作画チェック表）

本文件是四名角色的**共通**规范。任何单角色设定与本文冲突时，以单角色设定表为准。

- SD 版禁用 1 影以外的阴影层，线稿粗细统一。

## 2. 脸部作画基准

### 2.1 十字线

- 眼睛位于头部**纵向正中线略下**（0.52 处），这是本作偏"现代 TV 动画"的比例。
- 眼间距 = 1 个眼宽。
- 耳朵上缘对齐眉毛，下缘对齐鼻尖。

### 2.2 眼睛画法（本作的统一语言）

1. 上睫毛线**最粗**（主线的 1.3 倍），向眼尾方向加粗并延伸出一小段。
2. 虹膜占眼睛开口高度的 90%，上缘被上眼睑压住约 15%。
3. 瞳孔（黑点）占虹膜宽度的 1/2。
4. 高光**两点制**：主高光在 11 点钟方向（大圆），反射高光在 5 点钟方向（小点）。
   - 例外：忍的高光加大到 1/3 面积；墨的反射高光取消（无生气）。
5. 虹膜下缘做一层**透光渐变**（比底色亮 20%），这是本作眼睛通透感的来源。

### 2.3 三面对照的注意点

| 角度 | 要点 |
| --- | --- |
| 正面 | 严格对称，只有发型允许不对称 |
| 侧面 | 鼻尖—上唇—下巴构成的轮廓线是角色识别的第二要素，不要都画成一样 |
| 斜 45°（主力角度） | 远端眼睛宽度压缩到近端的 75%，不要压到 50% 以下 |
| 俯视 / 仰视 | 头部当作球体处理，十字线必须先起稿，禁止直接凭感觉画 |

## 3. 线稿规范（以 1920×1080 输出为基准）

| 线种 | 粗细 | 用途 |
| --- | --- | --- |
| 主轮廓线 | 3.0 px | 身体、服装外轮廓 |
| 内部结构线 | 2.0 px | 服装褶皱、五官 |
| 发丝线 | 1.5 px | 头发内部分线 |
| 细部线 | 1.0 px | 雀斑、纹样、缝线 |

- 线色：**不使用纯黑**。统一使用 `#2A2530`（暖黑）。
  头发与瞳孔的线条使用各自底色的加深版（色トレス），提升柔和度。
- 远景（全身入镜 1/3 以下）时，细部线全部省略，主线降到 2.0 px。

## 4. 赛璐璐上色分层

固定 7 层，从下到上：

1. **底色（ベース）**
2. **1 影** — 主光源产生的硬边阴影，明度 −18%、色相向蓝偏移 8°
3. **2 影** — 只用于遮蔽最深处（下巴下方、袖内、发根），明度 −32%
4. **高光** — 硬边，头发与金属材质专用
5. **眼睛专用层** — 独立管理，不受环境色影响（除非剧本指定）
6. **反射光（環境光）** — 轮廓内侧的一条细亮边，取环境主色
7. **特效层** — 灵性粒子 `#8FE3D6`、灯笼光 `#FFC46B`

**光源默认**：左上 45°。
**例外**：灯莉在夜戏中以灯笼（左下、暖橙）为主光，环境冷光为副光。

## 5. 表情差分の共通ルール

每个角色固定 **8 张**基础表情（见各自设定表），此外全员共通准备：

| 类型 | 张数 | 说明 |
| --- | --- | --- |
| 基础表情 | 8 | 角色个别指定 |
| 口型（リップシンク） | 6 | あ / い / う / え / お / ん（闭口） |
| 眨眼 | 3 | 开 / 半闭 / 闭。中间帧 2 格，闭眼帧 3 格 |
| 视线差分 | 5 | 正 / 左 / 右 / 上 / 下（只动瞳孔，不动眼型） |

**口型作画注意**：本作采用 6 型，但日常对话优先用「あ / い / ん」三型循环，
只有特写与决胜台词才用全 6 型，以控制工数。

## 6. 材质表现

| 材质 | 表现方法 |
| --- | --- |
| 棉布（半纏、雨衣） | 褶皱少而大，转折圆钝。高光不用 |
| 军装呢料（冴的大衣） | 褶皱锐利、直线为主。1 影面积大，边缘硬 |
| 麻布（墨的作务衣） | 褶皱细碎但不加深阴影，整体偏平 |
| 皮革（书包、靴） | 只在转折处加窄条高光，形状为长椭圆 |
| 黄铜 / 银（钥匙、扣子） | 三段式：暗底 + 中间色 + 一点纯白高光 |
| 灵体（忍、墨的崩解） | 下缘渐隐，叠加 `#8FE3D6` 粒子，不透明度 60% |
| 湿润的地面 | 角色的倒影只画剪影 + 30% 不透明度，且**忍没有倒影** |

## 7. 提交前检查表

作画监督用。每张原画交付前逐条确认：

- [ ] 头身比与设定表一致（用 3.5 头对照尺检查）
- [ ] 眼睛高光为两点制，位置正确（11 点 / 5 点）
- [ ] 线色为 `#2A2530`，未使用纯黑
- [ ] 配色 HEX 与设定表一致，未出现设定外的第 6 组颜色
- [ ] 角色持物未被省略（灯笼 / 袖手 / 伞枪 / 书包）
- [ ] 灯莉：呆毛未被裁切，且姿态与情绪一致
- [ ] 墨：站位在灯笼光的暗侧；无汗、无呼吸起伏、无暖调脸红
- [ ] 冴：手套未摘；全身红色仅限臂章与伞枪红线
- [ ] 忍：未画脚、未画影子、未画倒影；场景为雨天或雾夜
- [ ] 剪影测试：填黑后四人仍可区分
