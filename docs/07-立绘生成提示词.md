# 立绘生成提示词（Image Prompts）

本文件把四名角色的设定表压缩成可直接使用的作画／出图提示词。

**用法**：在 Cursor Agent 会话中打开本仓库，把下面「共通风格前缀」与任一段角色描述拼在一起，
并说明要生成图片（建议长宽比 **3:4**）即可。产出建议命名为 `assets/concepts/<id>.png`。

当前仓库已收录一组示例立绘（概念稿，非最终作画）：

## 共通风格前缀

所有角色共用，建议拼在每段角色描述之前：

```
日本动画角色设定立绘，全身站姿，纯白背景带浅灰网格线，角色设定资料集风格。
画风：现代日本 TV 动画赛璐璐上色，干净锐利的线稿，扁平色块加硬边阴影，不使用渐变。
主光源来自左上 45 度。全身完整入镜，头顶与脚部都不裁切。
```

英文版：

```
Japanese anime character design sheet, full body standing pose, pure white
background with light grey grid lines. Style: modern Japanese TV anime cel
shading, clean crisp line art, flat color blocks with hard-edged shadows,
no gradients. Key light from upper left 45 degrees. Full body in frame,
head and feet not cropped.
```

建议参数：**长宽比 3:4**（角色立绘）／**16:9**（主视觉）。

## 出图后的检查要点

按 [05-作画规范](05-作画规范.md) 的提交检查表核对，重点是这几条最容易出错：

- 灯莉的呆毛未被裁切，半纏袖子明显偏长
- 墨没有出现暖色脸红、汗水；站位在灯笼光的暗侧
- 冴全身只有臂章与伞枪红线是红色，手套未摘
- 忍没有画脚、没有影子、没有倒影
- 四人剪影填黑后仍可区分（雨衣尖帽／半纏方形＋呆毛／猫耳尾巴／马尾＋大衣下摆）
